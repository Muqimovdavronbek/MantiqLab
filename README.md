# MantiqLab

A planned learning environment for NAND/NOR logic circuits.

**Status: documentation only.** Application source code, installable packages and build scripts have not been uploaded to this repository. The planned scope includes a web interface, Android app and circuit learning materials; those deliverables are not present here.

## Repository access

```bash
git clone https://github.com/Muqimovdavronbek/MantiqLab.git
cd MantiqLab

```

You can also select **Code → Download ZIP** and extract the archive. These steps download the repository; there is currently no application to run or APK to build.
